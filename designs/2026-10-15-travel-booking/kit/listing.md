## Description

**Build a travel app that looks like it belongs on Dribbble, and actually works.**

Roam is a complete destination explorer + booking app UI for students and beginner front-end developers. Big travel photos, frosted glass pills, pill chips, 20px cards and one azure accent. Pale-sky light mode and deep teal-navy dark mode. Three linked screens in plain HTML, Tailwind CSS and vanilla JavaScript.

**What you get**
- **3 screens × 2 themes**: Home, Explore and Destination detail in light + dark
- **Home**: greeting + location pill, live search, category chips, tall photo cards with glass rating + heart pills, popular trips list
- **Explore**: Beaches / Mountains / Cities / Lakes chips, big feature card with a glass info panel, nearby escapes grid
- **Detail**: hero gallery (tap thumbnails), Top Facilities tiles, Read more, sticky price bar
- **Booking bottom sheet**: dates, guests stepper and live total, saved to localStorage
- **Favourites** (hearts) and **light/dark toggle**, both saved in localStorage
- **Floating frosted tab bar** and responsive desktop layout
- **11 demo destinations** in one `data.js` file + 14 local Unsplash photos (no broken images)
- **Original Google Stitch designs** (PNG + HTML) included
- **Zero setup**: Tailwind via CDN, no npm. Double-click `index.html`.
- **Clean, commented code** + README with palette and extension ideas

**Stack:** HTML · Tailwind CSS · vanilla JS · Plus Jakarta Sans

**Perfect for:** portfolio projects, learning glassmorphism + `backdrop-filter`, practising filtering/search with JS, hackathons and client mockups.
