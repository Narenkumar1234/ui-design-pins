## Description

**Build the project every recruiter understands: a budget app.**

Penny is a complete minimalist expense tracker for students and beginner front-end developers. Lots of whitespace, 1px hairlines, big light numerals and just two accent colours. Adding transactions, the monthly budget, insights and the light/dark toggle all actually work in plain HTML, Tailwind CSS and vanilla JavaScript.

**What you get**
- 3 pages × 2 themes = **6 screens**: Overview, Add expense, Insights, each in light and dark
- **Light/dark toggle** with Tailwind `dark:` classes, saved in localStorage
- **Working transactions**: add expense or income, view, delete; all saved in localStorage
- **Custom keypad** amount input (also works with a real keyboard)
- **Editable monthly budget** with a progress line that turns terracotta when you overspend
- **Insights**: Week / Month / Year totals, % change vs last period, CSS-only bar chart, category breakdown
- **₹ formatting** with `Intl.NumberFormat('en-IN')`
- **Demo data seeded around today's date**, works offline (file:// fallback included)
- **Zero setup**: Tailwind via CDN, no npm. Double-click `index.html`.
- **Clean, commented code** + README covering palette, structure and customisation
- **Reference screenshots** (kit + original Google Stitch designs, light + dark)

**Who it's for**
- Students who want a clean portfolio project
- Beginners learning DOM, localStorage, dates, number formatting and Tailwind
- Anyone who wants a minimal starter for a finance or habit app

**Why it helps you learn**
Interview-friendly topics: state in localStorage, derived totals, grouping by month/category, date ranges, `<dialog>`, theme switching and CSS-only charts. Read it, change the categories, then rebuild it in React.
