## Description

**Build the smart home app you'd actually want on your phone.**

Hearth is a complete smart home control flow for students and beginner front-end developers. Charcoal screens, ONE vivid orange accent, soft rounded cards, pill search, a floating nav with a centred orange + button, and a warm off-white light mode. Four linked pages in plain HTML, Tailwind CSS and vanilla JavaScript.

**What you get**
- **4 pages × 2 themes**: Welcome, Home, Room and Energy in charcoal dark + warm light
- **Welcome**: full-bleed living-room photo, 3-step intro with dots + swipe, slide-to-start pill
- **Home**: greeting, live "N on" counter, pill search, room filter chips, device cards with working toggles (one turns full orange while on), quick scenes
- **Room**: 270° thermostat dial you can drag (or use −/+ and arrow keys), Cool / Heat / Dry / Fan, fan speed, schedule; brightness slider with a live glow, 4 colour temperatures, per-lamp toggles; slide-to-power pill
- **Energy**: Day / Week / Month bar chart with tap-for-kWh tooltip, cost estimate, top devices, scenes (Good morning, Movie night, Away, Sleep) that switch real device state, CSV export
- **Add device** bottom sheet from the orange + button (name, room, type, validation)
- **Device state, scenes, rooms and theme saved in localStorage**, shared across pages
- **12 demo devices in 4 rooms** in one `data.js` file
- **Original Google Stitch designs** (PNG + HTML) and phone mockups included
- **Zero setup**: Tailwind via CDN, no npm. Double-click `code/index.html`.
- **Clean, commented code** + README with palette, file map and a full-stack build plan

**Stack:** HTML · Tailwind CSS · vanilla JS · Outfit

**Perfect for:** portfolio projects, practising state + localStorage, building custom controls (dial, slider, slide-to-confirm), learning dark-mode tokens, turning into a full-stack IoT app (Next.js + Node + MongoDB/Postgres + WebSockets/MQTT + JWT), hackathons and client mockups.
