## Description

**Build a study app that people actually want to open.**

Lumo is a complete e-learning flow for students and beginner front-end developers. Pale sky-blue screens, a periwinkle accent, pastel peach / cream / lavender tiles, chunky rounded headings and glossy 3D clay illustrations with cute faces. Light mode plus a deep-navy dark mode (not pure black). Four linked pages in plain HTML, Tailwind CSS and vanilla JavaScript.

**What you get**
- **4 pages × 2 themes**: Home, Explore, Lesson player and My learning (progress) in light + dark
- **Home**: clay mascot hero, Continue pill that resumes your last course, progress card with a live streak, pastel "Today's picks", popular courses
- **Explore**: filter pills, 2-column staggered subject grid, subject bottom sheet, live search by course, subject or teacher
- **Lesson player**: play / pause, seek bar, 1x / 1.5x / 2x speed, lesson list with done ticks, Next lesson, bookmark, autosaved notes and a 3-question quiz with score + badge
- **My learning**: 7-day streak tracker, weekly minutes chart with a daily-goal line (10 / 20 / 30 min), courses in progress, locked / unlocked badges
- **Progress, streak, notes, badges and theme saved in localStorage**, so everything survives refreshes and works across pages
- **8 transparent 3D clay illustrations** (lightbulb, books, pencil, laptop, trophy, flask, globe, grad cap)
- **6 subjects + 9 demo courses** in one `data.js` file
- **Original Google Stitch designs** (PNG + HTML) and phone mockups included
- **Zero setup**: Tailwind via CDN, no npm. Double-click `code/index.html`.
- **Clean, commented code** + README with palette, file map and extension ideas

**Stack:** HTML · Tailwind CSS · vanilla JS · Fredoka + Nunito

**Perfect for:** portfolio projects, practising state + localStorage, learning dark-mode tokens, turning into a full-stack LMS (React/Next.js + Node + MongoDB + JWT + Cloudinary video), hackathons and client mockups.
