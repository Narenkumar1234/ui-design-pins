## Description

**Build a food delivery app that looks hand-crafted, and actually works.**

Ember is a complete customer ordering flow for students and beginner front-end developers. Cream backgrounds, serif headlines with one italic terracotta phrase, big overhead food bowls, round category chips and 16-24px cards. Cream + terracotta light mode and a warm espresso dark mode (no neon). Five linked pages in plain HTML, Tailwind CSS and vanilla JavaScript.

**What you get**
- **5 pages × 2 themes**: Home, Restaurant, Dish detail, Cart/checkout and Live tracking in light + dark
- **Home**: delivery address, serif hero with an overhead bowl, live search across restaurants and dishes, round category chips, promo card with copy-code, "Popular near you" 2-column cards
- **Dish detail**: circle-cut hero photo, rating/time/kcal pills, extras checklist, quantity stepper and a **live total** in the Add to cart button
- **Cart**: line-item steppers, promo code **EMBER30** (30% off, capped at $10), bill summary, card / UPI / cash choice, Place order
- **Live tracking**: pure-SVG map with an animated courier, ETA countdown and a 4-step status timeline
- **Cart, promo, favourites and theme saved in localStorage**, so everything survives refreshes and works across pages
- **5-icon tab bar** with a cart badge and a floating "View cart" bar; responsive desktop layout
- **5 demo restaurants + 11 dishes** in one `data.js` file + local Unsplash photos (no broken images)
- **Original Google Stitch designs** (PNG + HTML) and cleaned mockups included
- **Zero setup**: Tailwind via CDN, no npm. Double-click `code/index.html`.
- **Clean, commented code** + README with palette, file map and extension ideas

**Stack:** HTML · Tailwind CSS · vanilla JS · Newsreader + DM Sans

**Perfect for:** portfolio projects, practising cart state + localStorage, learning dark-mode tokens, turning into a full-stack app (React/Next.js + Node + MongoDB + Stripe test mode), hackathons and client mockups.
