## Description

**Stop shipping another todo list. Ship a fitness tracker.**

Pulse Fit is a complete neo-brutalist workout mini-app for students and beginner front-end developers. Thick outlines, hard offset shadows, punchy lime/pink fills — and the streak, rest timer, exercise checklist and light/dark toggle all actually work in plain HTML, Tailwind CSS and vanilla JavaScript.

**What you get**
- 3 pages × 2 themes = **6 screens**: Today, Workout, Progress — each in light and dark
- **Light/dark toggle** with Tailwind `dark:` classes, saved in localStorage
- **Working streak** that increments when you complete today's workout
- **Rest timer** with Pause / Resume / Reset between sets
- **Exercise checklist** with sets×reps, progress bars, per-day memory
- **Weekly geometric bar chart**, PR cards, consistency calendar dots
- **Local workout JSON**, works offline (file:// fallback included)
- **Zero setup**: Tailwind via CDN, no npm. Double-click `index.html`.
- **Clean, commented code** + README covering palette, structure and customisation
- **Reference screenshots** (mobile light + dark)

**Who it's for**
- Students who want a bold portfolio project
- Beginners learning DOM, localStorage, timers and Tailwind
- Anyone who wants a neo-brutal starter for a fitness or habit app

**Why it helps you learn**
Interview-friendly topics: state in localStorage, countdown timers, derived progress, theme switching and CSS-only charts. Read it, tweak the workout data, then rebuild it in React.
