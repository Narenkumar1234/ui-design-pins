## Description

**Build the weather app you'd actually keep on your home screen.**

Nimbus is a complete weather flow for students and beginner front-end developers. A sky gradient that melts into a peach horizon, frosted-glass cards, a glowing sun, drifting clouds, gradient weather icons and a starry navy night mode. Five linked pages in plain HTML, Tailwind CSS and vanilla JavaScript.

**What you get**
- **5 pages × 2 themes**: Home, Forecast, Cities, Details and Settings in glass day + night
- **Home**: city pager, tap the temperature for °C / °F, Highlights card (rain alert + tomorrow's trend), 24-hour pills with Conditions / Rain / Wind tabs, next 3 days, AQI + UV
- **Forecast**: Temperature / Rain / Wind chart you can tap, drag or use with arrow keys, 10-day list with expandable rows
- **Cities**: search 20 cities, add up to 12, reorder + remove in Edit mode, local time on every card
- **Details**: AQI scale, UV, wind compass, sunrise/sunset arc, humidity, feels like, pressure gauge, visibility, each with an info sheet
- **Settings**: units with live preview, Day / Night / Auto theme, animated sky, alerts, live weather toggle, clear cache, reset
- **Optional live weather** from Open-Meteo (free, no key) with a 15-minute cache, timeout and offline fallback
- **Everything saved in localStorage**, shared across pages
- **Original Google Stitch designs** (PNG + HTML) and phone mockups included
- **Zero setup**: Tailwind via CDN, no npm. Double-click `code/index.html`.
- **Clean, commented code** + README with palette, file map and a full-stack build plan

**Stack:** HTML · Tailwind CSS · vanilla JS · Sora

**Perfect for:** portfolio projects, practising fetch + caching + localStorage, learning glassmorphism and dark-mode tokens, SVG charts, turning into a full-stack app (Next.js + weather API proxy + Redis cache + auth + saved cities + PWA push alerts), hackathons and client mockups.
