Glassmorphism Weather App UI: Nimbus Light + Dark · Front-End Project Idea

Front-end project idea: Nimbus, a glassmorphism weather mobile app UI. A home screen with a big thin temperature (tap for °C/°F), a frosted Highlights card with a rain alert, 24-hour forecast pills with Conditions / Rain / Wind tabs and a next-days list; a forecast screen with an interactive 24-hour temperature, rain and wind chart and a 10-day list; a saved-cities screen with search and reordering; a details screen with an AQI scale, UV index, wind compass, sunrise/sunset arc and pressure gauge; and settings for units, theme and live weather. Day mode is a blue-to-peach sky (#4FA3F7, #8CCBFF, #FFD6A5) with white 26% frosted-glass cards; night mode is a starry navy sky (#071026 to #1D3B78) with a soft moon. Sora font, sun accent #FFB238, rain #2578DE. Build it with HTML, Tailwind CSS and vanilla JavaScript (optional live data from the free Open-Meteo API with localStorage caching), then go full-stack with Next.js, a weather API proxy, Redis caching, auth + saved cities and PWA push alerts. A weather app UI kit from @code.in.30s, comment NIMBUS on Instagram for the HTML/CSS kit.
