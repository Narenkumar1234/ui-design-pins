## Description

**Stop building another to-do app. Build a shop.**

Flat Shop is a complete flat-design e-commerce mini app made for students and beginner front-end developers. It isn't just pretty screenshots: the cart, quantity steppers, promo code and light/dark toggle all actually work, in plain HTML, Tailwind CSS and vanilla JavaScript you can read top to bottom.

**What you get**
- 3 pages × 2 themes = **6 screens**: Home, Product detail, Cart, each in light and dark
- **Light/dark toggle** with Tailwind `dark:` classes, saved in localStorage
- **Working cart**: add to cart, qty steppers, remove items, live totals, cart badge, all saved in localStorage
- **Promo code** `FLAT20` = 20% off, plus a free-shipping threshold and order summary
- **Search + category filters**, a product grid and a promo banner
- **Product page** with size and color pickers (the color recolors the product) and a sticky mobile "Add to cart" bar
- **Local `products.json`**, so it works offline with no API key (a Fake Store API swap guide is included)
- **Fully responsive**: phone → tablet → desktop
- **Zero setup**: Tailwind via CDN, no npm or build step. Double-click `index.html`.
- **Clean, commented code** plus a README covering setup, file structure, palette and how to customise
- **12 reference screenshots** (mobile + desktop, light + dark)

**Who it's for**
- Students who want a portfolio project that looks professional
- Beginners learning DOM manipulation, localStorage and Tailwind
- Anyone who wants a flat-UI starter for a small store or a client demo

**Why it helps you learn**
Every feature is something interviewers ask about: state in localStorage, derived totals, event delegation, theme switching and responsive layouts. Read it, change it, then rebuild it in React as a next step.
