## Description

**Build the chat app your friends would actually use.**

Natter is a complete messaging flow for students and beginner front-end developers. A pale lavender page, ONE saturated violet accent, fully rounded bubbles with one tight corner, a stories row, a vertical violet action rail in the conversation and a deep violet-black dark mode. Five linked pages in plain HTML, Tailwind CSS and vanilla JavaScript.

**What you get**
- **5 pages × 2 themes**: Welcome, Chats, Conversation, Calls and Profile in lavender light + violet-black dark
- **Welcome**: full-violet onboarding, 3 intro steps with dots + swipe, round white arrow button with a progress ring
- **Chats**: pill search, stories row with a story viewer (auto-advance, reply) and your own text story, All / Unread / Groups / Pinned filters, unread badges, typing previews, long-press actions (pin, read, mute, delete), new chat + new group
- **Conversation**: send messages, typing indicator + fake auto-reply, read ticks, emoji reactions (tap or double-tap), reply by menu or swipe, voice notes you can record and play (waveform + seek), photo attach with upload preview + caption, location card, vertical action rail, voice/video call overlay, group info with members, admin role and shared media
- **Calls**: live group call card, All / Missed history, call back, calls you make get logged
- **Profile**: edit name + bio, status picker, privacy toggles, chat wallpaper, dark mode switch, reset demo
- **Everything saved in localStorage**, shared across pages
- **Initials-on-gradient avatars + original SVG images**, no stock photos
- **Original Google Stitch designs** (PNG + HTML) and phone mockups included
- **Zero setup**: Tailwind via CDN, no npm. Double-click `code/index.html`.
- **Clean, commented code** + README with palette, file map and a full-stack build plan

**Stack:** HTML · Tailwind CSS · vanilla JS · Poppins

**Perfect for:** portfolio projects, practising DOM state + localStorage, building chat UI patterns (bubbles, reactions, reply quotes, voice notes), learning dark-mode tokens, turning into a full-stack real-time app (Next.js + Node/Express + Socket.IO + MongoDB/Postgres + JWT + Cloudinary), hackathons and client mockups.
