Chat apps can feel this friendly 💬💜

Build this → Natter, a lavender + violet chat app

1️⃣ Welcome: full-violet onboarding, floating bubbles + voice note, "Talk more, type less." and a round white arrow button
2️⃣ Chats: pill search, a stories row with gradient rings, All · Unread · Groups · Pinned chips, rounded chat cards with unread badges and "typing…"
3️⃣ Conversation: violet header, white + violet bubbles with one tight corner, emoji reactions, swipe to reply, voice notes you can record and play, photo attach and a vertical violet action rail
4️⃣ Typing indicator + a fake auto-reply, so the chat actually talks back
5️⃣ Calls + Profile: live group call card, missed calls in pink, status picker, read receipts, chat wallpaper
6️⃣ Pale lavender light mode (#F1F0FF) as the hero + a deep violet-black dark mode (#120E24)

🎓 Student project idea: make it a full-stack real-time chat app. React/Next.js front end, Node + Express, Socket.IO for live messages, typing and presence, MongoDB or Postgres for users, chats and messages, JWT auth, read receipts, photo + voice uploads to Cloudinary or S3. Stretch: WebRTC calls, push notifications, end-to-end encryption
