## Description

**Track every application from wishlist to offer, and build the tracker yourself.**

Orbit is a complete job-tracker web app for students and new grads hunting internships and first jobs. An off-white canvas with white bento cards, a forest-green primary, a lime accent for what matters right now, Space Grotesk numbers and Geist UI text, plus a green-black dark mode. Five linked pages in plain HTML, Tailwind CSS and vanilla JavaScript, responsive from 360px phones to wide desktops.

**What you get**
- **5 pages × 2 themes**: Dashboard, Board, Application detail, Interviews and Settings, in light + dark
- **Dashboard**: stat cards, lime response-rate card, SVG weekly chart with a goal line (4 / 8 weeks), upcoming interviews, pipeline bar, activity feed, "next up" countdown, reminder banner
- **Kanban board**: drag and drop between and within columns, keyboard moves (Shift + arrows), card menu, undo, filters, sort, live search, status tabs on mobile
- **Application detail**: status menu, move to next stage, editable timeline, notes with autosave, contacts, salary details, .ics calendar invite
- **Interview calendar**: month view with keyboard navigation, day panel and a schedule form that moves the card to Interview
- **Settings**: weekly goal, Light / Dark / System theme, ₹ / $ currency, reminders, CSV import + export, reset demo
- **Add / edit modal** with validation, focus trap and two-step delete; global search with `/`; `N` adds an application
- **Everything saved in localStorage**, shared across pages; 17 fictional demo applications included
- **Original Google Stitch designs** (PNG + HTML) and desktop + mobile mockups included
- **Zero setup**: Tailwind via CDN, no npm. Double-click `code/index.html`.
- **Clean, commented code** + README with palette, file map and a full-stack build plan

**Stack:** HTML · Tailwind CSS · vanilla JS · Space Grotesk + Geist

**Perfect for:** portfolio projects, learning drag and drop + keyboard accessibility, localStorage state, SVG charts and dark-mode tokens, turning into a full-stack app (Next.js / React + Node/Express or Next API routes + Postgres + Prisma + auth + cron email reminders + S3 résumé uploads + analytics), hackathons and placement-season side projects.
