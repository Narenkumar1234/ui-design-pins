Minimal Reading Tracker App UI: Folio Light + Dark · Front-End Project Idea

Front-end project idea: Folio, a minimal book reading tracker mobile app UI. A home screen with a reading streak card and last-7-days bars, the book you're currently reading with a progress bar, a daily reading goal ring and a log-a-session sheet; a book detail screen with a large cover, rating, pages and genre pills, an Add to shelf pill, a 5-star rating and a Continue reading button; a library with search, status tabs and genre chips; a reader with tap-to-highlight and text settings; and a profile with stat tiles, a yearly reading goal, a shelf and favourite genres. Monochrome palette (ink #141414, paper #F5F4F0, grey #8A8A8A) with one orange accent #E8742A and yellow rating stars, Urbanist font, full-round pills, CSS-drawn book covers, plus a near-black dark mode. Build it with HTML, Tailwind CSS and vanilla JavaScript with localStorage, then go full-stack with Next.js, Postgres + Prisma, auth, Open Library API book search and streak reminder emails. A reading app UI kit from @code.in.30s, comment FOLIO on Instagram for the HTML/CSS kit.
