## Description

**Track every book, keep the streak going, and build the app yourself.**

Folio is a complete reading-tracker mobile app for students and book lovers. Off-white paper, near-black ink, quiet greys and a single orange accent, Urbanist type, full-round pills and CSS-drawn book covers (no images needed), plus a near-black dark mode. Five linked pages in plain HTML, Tailwind CSS and vanilla JavaScript, responsive from 360px phones to desktops.

**What you get**
- **5 pages × 2 themes**: Home, Book detail, Library, Reader and Profile, in light + dark
- **Home**: reading streak card with last-7-days bars, currently reading card with progress, daily goal ring, log-a-session sheet (pages + minutes), up next
- **Book detail**: big cover, facts pills, Add to shelf pill, want-to-read bookmark, your 5-star rating, Read more, "readers also liked", sticky Continue reading button
- **Library**: live search, status tabs with counts, genre chips, cover grid, empty state, URL-synced filters
- **Reader**: paged text, tap-to-highlight paragraphs, Aa sheet (size, line height, theme), buttons + arrow keys + swipe to turn pages, progress and streak update as you read
- **Profile**: stat tiles, orange longest-streak tile, yearly goal, shelf row, favourite genre chips, books-per-month bars, theme Light / Dark / System, daily goal stepper, reset demo
- **8 CSS cover styles** generated from data, so adding a book is one object in `data.js`
- **Everything saved in localStorage**, synced across pages and tabs; 8 fictional demo books included
- **Original Google Stitch designs** (PNG + HTML) and light + dark phone mockups included
- **Zero setup**: Tailwind via CDN, no npm. Double-click `code/index.html`.
- **Clean, commented code** + README with palette, file map and a full-stack build plan

**Stack:** HTML · Tailwind CSS · vanilla JS · Urbanist

**Perfect for:** portfolio projects, learning localStorage state, streak logic, bottom sheets and dark-mode tokens, and turning into a full-stack app (Next.js + Postgres/Prisma + auth + Open Library API search + streak reminder cron + social shelves), hackathons and placement-season side projects.
